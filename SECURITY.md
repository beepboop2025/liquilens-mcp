# Security policy

## Supported surface

Security reports are accepted for the current public LiquiLens MCP release, its hosted
endpoint at `https://api.liquilens.in/mcp`, and files in this repository. Historical
versions are not maintained as separate hosted services.

## Report privately

Email `mrinal@liquilens.in` with:

- a concise description of the issue and its likely impact;
- the affected URL, MCP method, tool, prompt, or repository file;
- reproducible steps or a minimal proof of concept;
- any mitigation you have already tested.

Do not include credentials, personal data, private institution data, or destructive
proofs. Please do not open a public issue before the report has been reviewed. Reports
are handled as capacity permits; there is currently no response-time SLA or bug bounty.

General product boundaries and data handling are documented in the public
[terms](https://liquilens.in/terms/) and [privacy notice](https://liquilens.in/privacy/).
